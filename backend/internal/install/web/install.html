Lyidc_OEM 安装向导

首次部署：全程在浏览器完成，无需手工编辑任何配置文件。配置文件写入位置：{{.ConfigPath}}

    正在读取安装状态…

    1. 环境检查

    确认服务可以写入配置文件、内嵌迁移文件完整，并查看运行信息。

    2. 数据库配置

    填写 MySQL 连接信息（5.7+）。密码只写入配置文件与内存，不会出现在日志或接口响应里。

    3. 初始化数据库

    执行内嵌迁移（0001 起全部）建表。可重复执行：已是最新版本时不会重复建表。

    4. 管理员账号

    安装后用它登录管理后台。系统自带的默认管理员（admin / admin123456）会被替换，库内不会残留默认凭据。

    5. 站点信息

    站点名称必填；站点地址用于生成支付回调等推荐地址，管理员邮箱为后续邮件通知预留（均可留空）。

    6. 完成安装

    将随机生成 JWT 密钥、把数据库连接与密钥合并写入配置文件，并写下安装标记。
